図解もテーブルも動画も。作成・検索・整理がひとつの画面で完結するセルフホスト型のナレッジ管理ツールです。Web版でもデスクトップ版でも、同じ使い心地で使えます。

デスクトップ版をダウンロード Web版として立ち上げる

特長

個人のメモから、チームで運用するナレッジベースまで。

📝

リッチな本文エディタ

見出し・テーブル・注意書き・画像・動画に加え、フローチャートやシーケンス図などのMermaid図解を本文中に直接挿入できます。

👥

チームでの権限管理

招待URLを発行してメンバーの参加を承認制に。プロジェクトは複数人のオーナーで共同管理でき、権限を柔軟に割り振れます。

🗂️

複数プロジェクトを分離管理

プロジェクト（ワークスペース）ごとに記事・フォルダ・タグが完全に分離。目的別にいくつでも作成・切り替えできます。

☁️

保存先を選べる

ローカルストレージのほか、AWS S3 / Google ドライブ / SharePoint Online / Box にも対応。プロジェクトごとに保存先を選択できます。

🛡️

管理者パネル

サーバー版では、初回起動時に決めた管理者アカウントからすべてのプロジェクト・ユーザーを横断的に管理できます。

💻

ログイン不要のデスクトップ版

Windows / Mac / Linuxのネイティブアプリとして単体で動作。ログイン不要ですぐに使い始められ、必要な時だけチームのサーバーに接続できます。

Web版として立ち上げる

チームで共有するサーバーとして運用する場合はこちら。Dockerを使う方法と、使わない方法の2通りをご案内します。

もっとも簡単な方法です。Docker / Docker Composeがインストールされていれば、コマンド一つで起動できます。

1. リポジトリを取得

git clone https://github.com/nishi-25/knowledge-tool.git
cd knowledge-tool

2. 起動

docker compose up --build

3. アクセス

ブラウザで http://localhost:8080 を開きます。初回アクセス時にアカウント作成、続けてプロジェクト作成のセットアップ画面が表示されます。

Dockerを使わず、バックエンド（Python）とフロントエンド（Node.js）を直接起動する方法です。

1. バックエンドを起動

cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

2. フロントエンドをビルドして配信

cd frontend
npm install
npm run build
npx serve -s dist -l 8080

フロントエンドを配信するサーバー側で、/api 宛のリクエストをバックエンド（http://localhost:8000）へリバースプロキシするよう設定してください（frontend/nginx.conf が設定例です）。

3. アクセス

ブラウザで http://localhost:8080 を開きます。

サーバー版では、初めて管理者パネル（/admin）を開いた人が管理者のユーザー名・パスワードを設定します。以降はそのアカウントですべてのプロジェクトを横断的に管理できます。

更新履歴

詳細な変更点は GitHub Releases でも確認できます。

v1.0.0
  • 初回リリース。記事の作成・検索・整理をワンビューで行えるナレッジ管理アプリ。
  • 見出し・テーブル・注意書き・画像・動画・Mermaid図解（フローチャート／シーケンス図／状態遷移図／ER図など）に対応したリッチな本文エディタ。
  • 複数プロジェクト管理、ログイン・チーム招待・承認制のアクセス権管理、複数オーナーによる共同管理に対応。

  • サーバー版向けの管理者パネル（初回起動時にアカウントを設定、全プロジェクト横断管理、ログイン機能の有効/無効切り替え）。
  • Windows / Mac / Linux向けデスクトップアプリ（ログイン不要のローカル動作、任意でサーバーに接続可能）。
