管理者パネル（サーバー版）

サーバー版には、すべてのプロジェクトを横断的に管理できる管理者アカウントがあります。デスクトップ版にはこの機能はありません。

初回セットアップ

サーバーを起動すると、初期設定トークンが自動生成されサーバーの起動ログに出力されます（docker compose logs backend で確認できます。ユーザーが何かを事前に設定する必要はありません）。/admin を開き、そのトークンを入力した上でユーザー名・パスワードを決めてください。一度設定すると、以降は誰でも初期設定画面には戻れず、通常のログイン画面になります。

管理者パネルでできること

  • ログイン機能の有効／無効切り替え：無効にすると一般ユーザーの新規登録・ログインができなくなります（メンテナンス時などに利用）。
  • メール（SMTP）配信設定：サーバー全体で使う通知メールの送信元アドレス・SMTPサーバーを設定します。承認通知やパスワード再発行などのメールはここで設定した情報で送信されます。未設定の場合、メール通知は送られません（アプリ内通知は設定不要で常に届きます）。
  • 管理者パスワードの変更：自分自身のパスワードをいつでも変更できます。
  • 全プロジェクトの一覧・横断管理：サーバー上のすべてのプロジェクトを、メンバーでなくても管理できます。
プロジェクトごとに、参加申請の承認・却下、メンバーの昇格・降格・削除、記事の移動・削除ができます。
💡 メール（SMTP）設定はサーバー全体で共有する認証情報のため、管理者パネルからのみ変更できます。プロジェクトの「設定」画面には変更機能はありません。
