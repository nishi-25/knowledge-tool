デスクトップ版の使い方

Windows / Mac / Linux 向けのネイティブアプリです。インストール後はログイン不要で、単体のローカルアプリとしてすぐに使い始められます。ダウンロードはトップページから。

基本的な使い方（記事の作成・編集・検索・整理）はWeb版と同じです。ただしデスクトップ版は1人のローカルユーザーとして動作するため、チームでの招待・承認やメンバー管理の機能は表示されません。

チームのサーバーに接続する

チームで運用しているKnowledge Viewサーバーがある場合、設定画面の「サーバーとの連携」から接続できます。接続してもローカルのデータは消えず、ローカルとサーバー、両方のデータを切り替えて使えます。

  1. サーバーのURLを入力し、「接続テストする」を押す（Knowledge Viewサーバーであることを自動で確認します）。
  2. 接続に成功すると「サーバーと接続しますか？」の確認が表示されるので、OKを押す。
  3. ログイン画面が表示されるので、そのサーバーのアカウントのメールアドレス・パスワードでログインする。

ログインすると「記事」画面のフォルダツリー上部に「ローカル」「サーバー」タブが表示され、いつでも行き来できます。設定画面の「連携を解除する」を押すと、サーバーとの連携自体を解除できます。
